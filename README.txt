# Lista de Asistencias

Primera versión web móvil de la aplicación.

## Cómo probarla
1. Descomprime `lista_asistencias_web.zip`.
2. Abre `index.html` con Google Chrome.
3. En Android puedes abrir el archivo con Chrome y usar "Añadir a pantalla de inicio" para tenerlo como acceso directo.
4. Los datos se guardan localmente en el navegador mediante localStorage.
5. Usa Configuración > Exportar respaldo para guardar una copia de seguridad.

## Funciones
- 4 grupos: A, B, C y D.
- Más de 150 personas por grupo.
- Carga masiva de nombres, uno por línea.
- Buscador.
- Fecha y actividad.
- Asistencia / justificación / falta automática.
- Historial mensual y estadísticas por persona.
- Exportación e importación de respaldo.
